# データと出典

`data/corpus.jsonl`と`data/evaluation_queries.json`は、本書の検索品質ハンズオン用に作成した架空データです。実在のメーカー、製品、型番、エラーコード、サポート事例、保証条件を表すものではありません。外部の文書やデータセットを転載・加工したものでもありません。

教材は、製品情報、エラーコード、接続事例、修理事例、取扱説明、ファームウェア、互換性、手入れ、設置、FAQ、保証、安全対応の12文書群、合計180チャンクで構成しています。似た型番、同じエラーコードを持つ別製品、解決した事例と未解決の事例、原則と例外を分割した文書などを含め、検索方式の違いを確認できるようにしています。

評価問い合わせはdev 50件とtest 50件に分けています。正解文書、期待文書、必須文脈チャンクが両方へまたがらないことを`validate_dataset.py`で検査します。

実行時に取得するモデルとソフトウェアの出典・ライセンスは[THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)を参照してください。
